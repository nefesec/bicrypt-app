01Installer l'app

1

Télécharge l'application

Depuis ton téléphone Android, ouvre cette page et touche le bouton ci-dessous :

Aller au téléchargement →

Un fichier bicrypt-X.X.X.apk va se télécharger.

2

Autorise l'installation

Quand tu ouvres le fichier .apk, Android affiche : « Installation d'applications inconnues ». Ce n'est pas dangereux — c'est le message standard quand l'app ne vient pas du Play Store.

Touche Paramètres → active « Autoriser depuis cette source » → reviens en arrière.

3

Installe

Touche Installer. Au bout de 10-20 secondes, l'app est prête.

Pourquoi pas le Play Store ? BiCrypt ne passe pas par Google pour rester totalement indépendant. Aucune donnée n'est partagée avec Google, Apple ou qui que ce soit.

02Premier lancement

1

Choisis un pseudonyme

Ce sera ton nom affiché aux contacts. Tu peux le changer plus tard. Pas besoin de ton vrai nom — un pseudo est mieux pour la confidentialité.

2

Accepte les conditions et appuie sur Créer mon identité.

3

Crée un code PIN à 6 chiffres

Ce code protège ton accès. Mémorise-le bien — si tu l'oublies, il faudra recréer un compte (et tes contacts ne te reconnaîtront plus).

Patiente 2 à 3 minutes au premier démarrage. En haut, le badge passe par « Démarrage… » → « Connexion… » → « En ligne » (vert). C'est BiCrypt qui se connecte au réseau Tor. Les fois suivantes, c'est rapide.

03Ajouter un contact

Pour discuter avec quelqu'un, il faut d'abord l'ajouter. Deux méthodes :

Méthode A — code d'invitation (la plus simple)

  1. Ta personne ouvre BiCrypt, va sur son profil (pseudo en haut à droite).
  2. Elle touche « Générer un code d'invitation » → un code apparaît (genre kfm-tj2-9hp).
  3. Elle te partage ce code (SMS, oral, papier — utilisable une seule fois).
  4. Sur ton téléphone, touche « Ajouter un contact » → colle le code → Utiliser ce code.
  5. Tu es ajouté automatiquement.

Méthode B — QR code en personne

  1. Vous êtes physiquement ensemble.
  2. Elle ouvre son profil → un QR code s'affiche.
  3. Tu touches « Ajouter un contact » → l'appareil photo s'ouvre, tu scannes son QR.
  4. Elle fait pareil avec ton QR.
À savoir : le code d'invitation expire après 24 heures ou dès qu'il est utilisé (usage unique). Pour plusieurs personnes, regénère un nouveau code à chaque fois.

04Envoyer un message

1

Touche le nom de la personne dans la liste « Messages privés » de l'accueil.

2

Écris ton message dans le champ en bas, puis touche la flèche pour envoyer.

3

Envoyer une photo : touche le bouton Photo à gauche du champ texte → « Prendre » ou « Galerie ».

4

Envoyer un vocal : maintiens le bouton d'enregistrement à droite (quand le champ est vide) → parle → relâche pour envoyer.

05Questions fréquentes

Pourquoi c'est lent au démarrage ?

BiCrypt se connecte au réseau Tor pour cacher complètement ton IP et tes métadonnées. Au premier lancement (ou après un redémarrage du téléphone), compte 2 à 3 minutes. Ensuite, c'est quasi instantané.

Mes messages sont vraiment privés ?

Oui. Chaque message est chiffré sur ton téléphone avec une clé que seul ton destinataire peut déchiffrer. Le relais ne voit que des données chiffrées — illisibles pour qui que ce soit, nous compris.

Que se passe-t-il si je perds mon téléphone ?

Ton compte n'existe que sur ce téléphone (la clé privée ne le quitte jamais). Si tu changes d'appareil, tu devras recréer un compte. C'est intentionnel : ça garantit qu'aucun serveur ne peut être saisi avec tes données.

Je peux recevoir des messages quand l'app est fermée ?

BiCrypt fonctionne quand l'app est ouverte (avant-plan ou arrière-plan). Si tu la fermes complètement, tu ne reçois pas en temps réel — mais les messages t'attendent côté relais pendant 24h et arrivent dès que tu rouvres l'app.

Comment supprimer mon compte ?

Profil (pseudo en haut à droite) → « Supprimer mon compte » → confirmer 2 fois. Toutes tes données sont effacées définitivement de ton téléphone. Pas de récupération possible.

« Ignorer les optimisations de batterie », c'est dangereux ?

Non. C'est pour garder la connexion active pendant que l'app est en arrière-plan. Tu peux refuser, mais les messages mettront plus longtemps à arriver. Réglable à tout moment dans les paramètres Android.

Comment mettre à jour ?

L'app vérifie les mises à jour régulièrement (environ chaque heure). Quand une nouvelle version est disponible, un bandeau apparaît en haut — touche-le pour installer. Rien d'autre à faire.

BiCrypt — sans publicité, sans collecte de données, sans abonnement.
