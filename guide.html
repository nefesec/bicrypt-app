Installer et utiliser BiCrypt

Pas à pas, même si tu n'es pas à l'aise avec la technique. Compte 5 minutes, connexion au réseau Tor comprise.

1. Installer l'application

BiCrypt fonctionne sur Android 8 ou plus. Il n'existe pas de version iPhone pour le moment.

  1. Télécharge le fichierSur ton téléphone, ouvre la page de téléchargement et touche Télécharger pour Android. Un fichier bicrypt-X.Y.Z.apk arrive dans tes téléchargements.
  2. Ouvre-leTouche la notification de téléchargement, ou ouvre le fichier depuis l'application Fichiers.
  3. Autorise l'installationAndroid affiche « Pour votre sécurité, l'installation d'applications inconnues est bloquée ». Touche Paramètres, active Autoriser depuis cette source, puis reviens en arrière.
  4. InstalleTouche Installer. Si Play Protect affiche un avertissement, touche Plus de détails puis Installer quand même.
Cet avertissement est normal. Android l'affiche pour toute application qui ne vient pas du Play Store. BiCrypt n'y est pas pour rester indépendant de Google. Pour être sûr d'avoir le vrai fichier, vérifie son empreinte.

2. Premier lancement

  1. Choisis un pseudoC'est le nom que verront tes contacts. Pas besoin de ton vrai nom : rien n'est envoyé, tu restes anonyme.
  2. Accepte les conditionsCoche J'accepte les Conditions d'utilisation, puis touche Continuer.
  3. Crée ton code PIN à 6 chiffresTape-le deux fois. Il protège l'accès à l'application. Si ton téléphone le permet, tu pourras aussi déverrouiller avec ton empreinte.
  4. Laisse BiCrypt rester connectéBiCrypt te demande une fois d'ignorer les optimisations de batterie : accepte pour recevoir tes messages même quand l'application n'est pas à l'écran. Ce n'est pas dangereux et tu peux le changer à tout moment.
Le premier démarrage prend de 30 secondes à 3 minutes. BiCrypt se connecte au réseau Tor. Le badge en haut à droite passe à En ligne quand c'est prêt. Les fois suivantes, c'est beaucoup plus rapide.
Retiens bien ton PIN. Il n'existe aucune récupération : personne, nous compris, ne peut le réinitialiser. Après 5 erreurs, l'application se bloque 15 minutes.

3. Ajouter quelqu'un

Sur l'accueil, touche ＋ Ajouter quelqu'un en bas de l'écran. Deux façons de faire :

Vous êtes ensemble : le QR code

  1. L'un montre son QR codeIl touche Montrer mon QR code.
  2. L'autre le scanneIl touche Scanner son QR code et vise l'écran de l'autre.

À distance : le code à usage unique

  1. La personne crée un codeElle touche la pastille avec son initiale en haut à droite (Mon profil), puis Créer un code. Un code du type kfm-tj2-9hp apparaît.
  2. Elle te l'envoieAvec le bouton Partager : SMS, e-mail, à l'oral, sur papier…
  3. Tu l'entresDe ton côté : ＋ Ajouter quelqu'un puis Entrer un code reçu. Vous apparaissez chacun dans les conversations de l'autre.
Un code ne sert qu'une fois et expire au bout de 24 heures. Pour ajouter plusieurs personnes, crée un nouveau code pour chacune. Notre relais ne voit jamais le code lui-même.

4. Discuter

  • Écrire : touche le nom de la personne dans Conversations, écris en bas, puis envoie.
  • Photo : touche Photo, puis Prendre une photo ou Choisir une photo. La position GPS et les autres métadonnées sont retirées avant l'envoi. Limite : 1 Mo après compression.
  • Vocal : touche le bouton Message vocal pour enregistrer (30 secondes maximum).
  • Hors ligne : si ton contact n'est pas connecté, son message l'attend sur le relais, chiffré, pendant 24 heures maximum. Si tu n'as plus de réseau, tes messages partent dès que tu es reconnecté.

5. Les groupes

Touche # Groupes en bas de l'accueil.

  • Créer un groupe privé : donne-lui un nom (par exemple « Famille ») et touche Créer le groupe. Dans le groupe, touche + Inviter : un code à usage unique est créé, à envoyer à chaque personne.
  • Rejoindre un groupe : entre le code d'invitation qu'on t'a envoyé.
  • Le groupe Général est public, ouvert à tous les utilisateurs de BiCrypt : n'y écris rien de personnel.

Quelqu'un te dérange dans un groupe ? Appuie longuement sur un de ses messages pour le masquer. Tu peux le démasquer dans les réglages.

6. Réglages utiles

Touche ⚙︎ en haut à droite de l'accueil.

  • Masquer dans les captures d'écran : empêche les captures et cache le contenu dans l'aperçu des applications récentes.
  • Photos et vocaux : efface-les automatiquement de ton téléphone après un délai, ou tout de suite.
  • Rester connecté en arrière-plan : à activer si tes messages arrivent en retard.
  • Langue : français ou allemand.

Effacer ses données

  • Effacer les messages : dans les réglages, efface messages, photos et vocaux, et quitte les groupes. Ton compte et tes contacts restent.
  • Supprimer mon compte : dans Mon profil. Tout est effacé définitivement de ton téléphone, sans récupération possible.

7. En cas de souci

Le badge reste sur « Connexion… »

Vérifie que tu as Internet (Wi-Fi ou données mobiles), puis patiente quelques minutes : le réseau Tor est parfois lent. Si ça bloque encore, ferme complètement l'application et rouvre-la.

Les messages arrivent en retard

Android a probablement mis BiCrypt en veille. Dans les réglages de BiCrypt, active Rester connecté en arrière-plan.

Comment mettre à jour ?

L'application vérifie les mises à jour toute seule, environ une fois par heure. Quand une version est disponible, un bandeau apparaît : touche-le pour l'installer. Chaque mise à jour est vérifiée par signature avant installation.

J'ai changé de téléphone

Ton identité ne quitte jamais l'ancien téléphone, c'est voulu. Installe BiCrypt sur le nouveau, crée une nouvelle identité et ré-ajoute tes contacts.
