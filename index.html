Politique de confidentialité
Dernière mise à jour : 27 avril 2026

BiCrypt est conçu selon le principe du Privacy by Design. Ce que nous ne collectons pas ne peut pas être volé, partagé ou compromis.

1. Responsable du traitement

Le traitement des données est effectué localement par l'utilisateur. Le développeur n'a aucun accès aux données créées ou échangées via l'application.

2. Données stockées sur votre terminal

  • Clés cryptographiques (Ed25519 / X25519) générées localement. La clé privée est protégée par l'Android Keystore (hardware-backed) ou l'équivalent système Desktop.
  • Code PIN : jamais stocké en clair. Seul un hash blake2b non réversible est conservé localement.
  • Contacts (pseudonymes + identifiants) : stockés dans la base chiffrée locale de l'application.
  • Messages : chiffrés de bout en bout. Seule votre clé privée locale peut les déchiffrer.

3. Transit des données (le Relais)

  • Le relais (.onion) agit comme un commutateur en mémoire vive. Les messages chiffrés y transitent puis sont immédiatement supprimés — aucune persistance.
  • Aucun journal de connexion, timestamp ou identifiant n'est conservé par le relais.
  • Votre adresse IP réelle n'est jamais exposée.

4. Base légale

L'utilisation repose exclusivement sur votre consentement. En générant vos clés, vous initiez le traitement de vos données pour la finalité unique de communication privée.

5. Vos droits (RGPD)

BiCrypt ne détenant aucune donnée sur ses serveurs, l'exercice de vos droits s'effectue directement sur votre appareil :

  • Accès / portabilité : consultez vos messages et clés directement dans l'application.
  • Effacement : désinstallez l'application. La suppression est définitive — aucune sauvegarde n'existe côté développeur.

6. Sécurité

Primitives cryptographiques : X25519, XSalsa20-Poly1305, Ed25519, blake2b-256. La sécurité dépend également de l'intégrité de votre propre appareil.

7. Transferts internationaux

Le réseau Tor implique que les fragments de messages chiffrés transitent par des nœuds intermédiaires répartis dans le monde entier. Ces données sont illisibles pour les tiers et ne permettent pas de vous identifier.

8. Bibliothèques tierces

BiCrypt s'appuie sur les bibliothèques suivantes :

  • @noble/curves — Ed25519 + X25519. Audit indépendant Cure53 (2023). Pure-JS, sans dépendance native.
  • @noble/ciphers — XSalsa20-Poly1305 conforme RFC 7539 / 8439.
  • @noble/hashes — Blake2b et SHA-256 (audit Cure53).
  • socket.io-client 4.8 — WebSocket sur Tor SOCKS5.
  • react-native-keychain / Android Keystore — stockage de la clé privée, hardware-backed sur les appareils compatibles.
  • react-native-vision-camera — lecture QR code. Aucune image stockée ni transmise.
  • Tor (binaire embarqué) — versions stables uniquement, circuits éphémères, aucun pont par défaut.

Les versions exactes sont publiées avec chaque release (package.json intégré à l'APK).

9. Mises à jour signées

Toute mise à jour est signée Ed25519 avec une clé dédiée distincte des clés utilisateur. L'application refuse toute installation dont la signature ou l'empreinte ne correspond pas.

10. Contact

Pour toute question relative à la protection de vos données, l'application intègre un canal de support en interne.
