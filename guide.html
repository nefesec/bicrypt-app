BiCrypt — Mode d'emploi

Guide pas-à-pas pour installer et utiliser BiCrypt, même si tu n'es pas à l'aise avec la technique.

1. Installer l'app sur ton téléphone

1Télécharge l'application

Depuis ton téléphone Android, ouvre cette page et touche le bouton ci-dessous :

Aller au téléchargement

Un fichier bicrypt-X.X.X.apk va se télécharger.

2Autorise l'installation

Quand tu ouvres le fichier .apk, Android va t'avertir : "Installation d'applications inconnues". Ce n'est pas dangereux — c'est juste le message standard quand l'app ne vient pas du Play Store.

Touche Paramètres → active "Autoriser depuis cette source" → reviens en arrière.

3Installe

Touche Installer. Au bout de 10-20 secondes, l'app sera prête.

Pourquoi pas le Play Store ? BiCrypt ne passe pas par Google pour rester totalement indépendant. Aucune donnée n'est partagée avec Google, Apple ou qui que ce soit.

2. Premier lancement

1Choisis un pseudonyme

Ce sera ton nom affiché aux contacts. Tu peux le changer plus tard. Pas besoin de mettre ton vrai nom — un pseudo est mieux pour la confidentialité.

2Accepte les conditions

Coche la case et appuie sur Créer mon identité.

3Crée un code PIN à 6 chiffres

Ce code protège ton accès. Mémorise-le bien — si tu l'oublies, il faudra recréer un compte (et tes contacts ne te reconnaîtront plus).

Attends 2 à 3 minutes au premier démarrage. En haut, le badge va passer par "Démarrage…" → "Connexion…" → "En ligne" (vert). C'est BiCrypt qui se connecte au réseau privé Tor. Les fois suivantes, c'est rapide.

3. Ajouter un contact

Pour discuter avec quelqu'un, il faut d'abord l'ajouter. Deux méthodes :

Méthode A : avec un code d'invitation (la plus simple)

  1. Ta personne ouvre BiCrypt sur son téléphone, va sur son profil (son pseudo en haut à droite)
  2. Elle touche "Générer un code d'invitation" → un code apparaît (genre kfm-tj2-9hp)
  3. Elle te partage ce code (SMS, oral, papier, peu importe — le code n'est utilisable qu'une seule fois)
  4. Sur ton téléphone, touche "Ajouter un contact" en bas → colle le code → Utiliser ce code
  5. Tu es ajouté automatiquement. Tu peux lui écrire tout de suite.

Méthode B : avec un QR code en personne

  1. Vous êtes physiquement ensemble.
  2. Elle ouvre son profil → un QR code est affiché.
  3. Tu touches "Ajouter un contact" → l'appareil photo s'ouvre, tu scannes son QR.
  4. Elle fait pareil de son côté avec ton QR.
Le code d'invitation expire après 24 heures ou dès qu'il est utilisé (à usage unique). Si tu veux le donner à plusieurs personnes, regénère un nouveau code à chaque fois.

4. Envoyer un message

1Touche le nom de la personne dans la liste "Messages privés" de l'accueil.

2Écris ton message dans le champ en bas, puis touche la flèche pour envoyer.

3Envoyer une photo : touche le bouton Photo à gauche du champ texte → choisis "Prendre" ou "Galerie".

4Envoyer un vocal : touche le bouton rond ● à droite (quand tu n'as rien écrit) → parle → touche ✓ pour envoyer.

5. Questions fréquentes

Pourquoi c'est lent au démarrage ?

BiCrypt se connecte au réseau privé Tor pour cacher complètement ton IP et tes métadonnées. Au premier lancement après installation ou redémarrage du téléphone, ça met environ 2 à 3 minutes pour établir la connexion. Les fois suivantes, c'est instantané.

Mes messages sont vraiment privés ?

Oui. Chaque message est chiffré sur ton téléphone avec une clé que seul ton destinataire peut déchiffrer. Le serveur ne voit que des données chiffrées — impossible à lire pour qui que ce soit, même nous.

Que se passe-t-il si je perds mon téléphone ?

Ton compte n'est récupérable que sur ce téléphone (la clé privée ne quitte jamais l'appareil). Si tu changes de téléphone, tu devras recréer un compte. C'est intentionnel : ça garantit qu'aucun serveur ne peut être saisi avec tes données.

Je peux recevoir des messages quand l'app est fermée ?

Non. BiCrypt ne fonctionne que quand l'app est ouverte (en avant-plan ou en arrière-plan). Si tu fermes complètement (swipe hors récentes), tu ne recevras pas en temps réel — mais les messages t'attendent côté serveur pendant 24h et arrivent dès que tu rouvres l'app.

Comment supprimer mon compte ?

Profil (pseudo en haut à droite) → "Supprimer mon compte" → confirmer 2 fois. Toutes tes données sont effacées définitivement de ton téléphone. Pas de récupération possible.

L'app demande "Autoriser à ignorer les optimisations de batterie", c'est dangereux ?

Non. C'est juste pour que la connexion privée reste active pendant que l'app est en arrière-plan. Tu peux refuser, mais alors les messages mettront plus longtemps à arriver. Tu peux changer ce réglage à tout moment dans les paramètres Android.

Comment mettre à jour ?

L'app vérifie automatiquement les mises à jour toutes les 6 heures. Quand une nouvelle version est disponible, un bandeau apparaît en haut — touche-le pour installer. Aucune intervention de ta part n'est nécessaire.

BiCrypt est un logiciel libre, sans publicité, sans collecte de données, sans abonnement.
